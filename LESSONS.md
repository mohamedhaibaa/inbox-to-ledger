# Lessons log

Every problem I hit while building Inbox to Ledger: what happened, why it matters, and what I did. Ordered by build step. The most important ones are summarised in the [README](README.md#lessons-problems-i-hit-and-how-i-solved-them).

| Step | What happened                                                                                                      | Why it matters                                                                                                     | What I did                                                                                                                               |
| ---- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 0    | Push failed with 403: Git used another saved GitHub account                                                        | Several accounts on one machine silently pick the wrong identity                                                   | Username in the remote URL; fine-grained token scoped to this repo                                                                       |
| 0    | Pasted commands containing `# comments` failed with "No such file"                                                 | zsh doesn't treat `#` as a comment when pasted interactively                                                       | Paste commands without comments                                                                                                          |
| 1    | Two investors share the bank reference "JE"                                                                        | A bank line "JE" can't identify the payer; guessing could credit the wrong investor                                | Kept it on purpose as a test case; the matcher uses fund context and sends true ambiguity to review                                      |
| 1    | Typing the GitHub password at the push prompt failed                                                               | GitHub only accepts tokens for Git over HTTPS                                                                      | Token at the prompt; macOS keychain stores it                                                                                            |
| 4    | A test file was saved in `pipeline/`, and tests still passed                                                       | pytest finds `test_` files anywhere, so a misplaced file doesn't fail loudly                                       | `git mv` to `tests/`; check each commit's file list                                                                                      |
| 5    | Classifier 100% accurate, but 32/39 documents under 80% confidence with default settings                           | Accuracy and confidence are different; an over-cautious model defeats a cheap first pass                           | Compared C = 1/10/50/100, chose the smallest that works (C=10); nonsense text still scores ~0.54                                         |
| 6    | A screenshot showed the API key                                                                                    | A visible key is a leaked key; `.gitignore` protects Git, not screenshots                                          | Revoked and replaced the key; never screenshot `.env`                                                                                    |
| 5–6  | `models/` kept showing as untracked: `.gitignore` ended with `models/models/`                                      | `echo >>` appended without a newline, so the rule silently matched nothing                                         | Fixed by hand; verify ignore rules with `git status`                                                                                     |
| 7    | A commit was made with a message that didn't describe its change                                                   | Misleading history; reviewers read it                                                                              | Left pushed history alone; only run the current step's commit, `git status` first                                                        |
| 7b   | The hard-set generator produced two documents with the same fund, investor and call                                | Validation rightly flagged a "duplicate": the test data was wrong, not the pipeline                                | Generator tracks used combinations; dry-ran scoring with a fake extractor before paying for API calls                                    |
| 7b   | On unseen layouts, 31/37 documents fell below 80% classifier confidence (all labels right)                         | The model knows it hasn't seen these layouts: the threshold is working                                             | Never train on the hard set; fix later with more varied training layouts and an LLM fallback                                             |
| 7b   | First hard-set run: 12 silent errors, all in `reference`; the eval didn't show what Claude returned                | You can't fix what you can't see                                                                                   | Grouped failures by layout (0/16, 7/9, 5/5 wrong), then changed the eval to print expected vs got before fixing anything                 |
| 7b   | Claude copied text after the reference (`JF CAP CALL 1 (drawdown no. 1)`)                                          | The schema never said where a reference ends                                                                       | Field description with a boundary rule and an example in a _different_ format (no test leakage): 28/40 → 40/40, original set still 30/30 |
| 9    | First matcher gave 4 silent errors ("Lake Chad Insurance Co." → Lake Chad Foundation); 5 scorers couldn't fix it   | Letter similarity can't tell a different investor from a cut-off name                                              | Compare only the distinctive part, reject a different kind of investor, restrict to the fund's investors: 0 silent                       |
| 9    | My "test" name variants came out almost identical to the dev set I tuned on                                        | A test that copies the tuning set grades you on answers you've seen                                                | Made variants genuinely random per seed: honest 796/802, 0 silent                                                                        |
| 10   | Step 10's commit was skipped; GitHub had code importing files that weren't committed                               | "Works on my machine": a clone would fail                                                                          | Committed the missing files; `git status` must be clean after each step; CI will catch this automatically                                |
| 10b  | Statement reader crashed on a 2-page statement (page-2 lines merged with page-1)                                   | Invisible on 1-page statements; another layout could merge amounts silently                                        | Group words by (page, line); a row must start with a date and end with an amount; 60-line test                                           |
| 10b  | Silent mislabel: two distributions of exactly $577,500 to one investor; January's wire credited to November's      | Totals still balance, so the error looks fine                                                                      | Same investor + amount → item due closest to the payment date; added `not_due` for distributions; confirmed on 3 fresh seeds             |
| 11   | The first queue design would have kept items open after their problem went away                                    | A queue full of stale items stops being trusted                                                                    | Each run closes what it no longer sees (by "system", with a note), never touching human decisions; replayed 61 mornings                  |
| 11   | I claimed amount could never outrank kind in priority, but two weights were only 5 apart                           | Explaining code precisely is a form of review                                                                      | Weights 10 apart, bonus capped at +9, test added                                                                                         |
| 12   | `answer()` returned text even when its only citation was a document it was never given                             | An untraceable answer is the RAG version of a silent error                                                         | No valid citation, no answer; also kept 1-character words in TF-IDF so "call 1" ≠ "call 2"                                               |
| 12   | Hallucination risk: questions no document answers (e.g. a management fee)                                          | An LLM can answer from general knowledge ("2%, like most funds"); in finance an invented number is worse than none | Prompt + code rule + 10 unanswerable test questions: all 10 refused                                                                      |
| 12   | Expected embeddings to beat keyword retrieval; they did worst (53/57 vs 57/57 in top 4)                            | Fund-admin questions hinge on names and codes a general model doesn't know                                         | Kept keyword retrieval; "embeddings are better" is a hypothesis to measure                                                               |
| 12   | Answers repeated day/month dates (`02/07/2026` = July 2); my generator asked one question with two "right" answers | An ambiguous date is as risky as a wrong one; a test with two answers measures nothing                             | Unambiguous-date rule; conflicting reports became a "conflict" question kind; eval stays strict                                          |
| 12   | Claude still refused the one conflict question after a "report conflicts" rule                                     | With one example, more prompt tweaks can't be told apart from luck                                                 | Stopped tuning; documented limitation; next: a conflict test set                                                                         |
| 13   | `ssm:PutParameter` denied in ca-central-1 even with AdministratorAccess                                            | An organization's service control policy beats any IAM permission; the error said so                               | Confirmed which services work in the allowed region (us-east-2) and deployed there; code unchanged                                       |
| 13   | First deploy failed: Lambda memory must be ≤ 512 MB                                                                | Accounts can have limits below AWS maximums; rollback left nothing behind                                          | MemorySize 512 (pipeline needs ~300 MB); deleted the `ROLLBACK_COMPLETE` stack and redeployed                                            |
| 13   | A scan right after uploading 10 files showed only 7 results; a joblib warning appeared in the logs                 | Queue-based systems are eventually consistent; not every warning is an error                                       | 30 s later: 11/11, dead-letter queue empty; the warning is Lambda having no `/dev/shm` (harmless)                                        |
| 8    | Streamlit warned that `use_container_width` is deprecated                                                          | A deprecation warning today is a crash after the next upgrade                                                      | Switched to `width="stretch"`; app tests run with no warnings                                                                            |
| 8    | The first README diagram rendered too wide to read                                                                 | A diagram nobody can read explains nothing                                                                         | Rendered both diagrams with the Mermaid CLI and switched the long one to top-down                                                        |
